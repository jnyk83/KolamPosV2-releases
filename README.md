- Android 8.0 or later (API 26+).
- Package: `com.kolampos.cloud`; Android version code: **74**.
- Install over the existing KolamPOS Cloud app. **Do not uninstall first.** Complete any active checkout before installing. An in-place update retains the terminal's local data and binding.
- Existing supported apps can check for this release through the update prompt or **Settings > App Info > Check for updates**.
- Open the updated app and sync. Update every bound tablet to a compatible version before using Custody; build 74 is recommended for all tablets.

This release adds aquatic types per pond, scheduled package pricing, Cash In/Out reason presets, stored fishing time (Custody), and RM/% item discounts with presets for packages, extensions and goods. It also improves access to session actions on short screens.

Redeem is operated by staff with physical stamp cards; it does not include digital stamp counting or automatic qualifying-purchase enforcement. Tournament Lite is not included.
