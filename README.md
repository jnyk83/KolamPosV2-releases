- Android 8.0 or later (API26+).
- Package: `com.kolampos.cloud`; Android version code: **62**.
- Install over the existing KolamPOS Cloud app. **Do not uninstall first.** Complete an active checkout before installing. An in-place update retains the terminal's local data and binding.
- Existing supported apps can check for this release through the update prompt or App Info.

This release adds selected-day history downloads after TAC activation/rebinding, online refunds for restored bills with remaining-balance checks, saved catalogue ordering, product search, slot filters and improved payment layouts.
