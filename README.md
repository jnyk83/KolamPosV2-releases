- Android 8.0 or later (API 26+).
- Package: `com.kolampos.cloud`; Android version code: **67**.
- Install over the existing KolamPOS Cloud app. **Do not uninstall first.** Complete any active checkout before installing. An in-place update retains the terminal's local data and binding.
- Existing supported apps can check for this release through the update prompt or Settings > App Info > Check for updates.

Customers can now be created and edited on Tablet and Admin, searched by name or phone, and selected by long-pressing an empty slot. Offline customer conflicts require explicit staff confirmation; original bill names and amounts are preserved. Purchase history and archiving remain in Admin.

Update **every bound tablet** to build 67 or later, then open the app and sync to enable Customers. Admin Portal v2.15.0 lists any tablets still needing an update.
