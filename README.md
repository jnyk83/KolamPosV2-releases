- Package: `com.kolampos.cloud`; Android version code: **75**.
- Finish any checkout, then install over the existing KolamPOS Cloud app. **Do not uninstall first.** An in-place update retains local data and device binding.
- Existing supported apps can use **Settings > App Info > Check for updates** and follow Android's installation confirmation.
- Open the updated app and sync. Update every bound tablet to the latest compatible version.

Build75 improves void synchronization, merged/split payments, refund safeguards, Counter cart recovery and stored-time session reminders. All five enhancements from build74 remain: aquatic types per pond, scheduled package pricing, Cash In/Out presets, Custody and RM/% item discounts.

Redeem is operated by staff with physical stamp cards; digital stamp counting and automatic qualifying-purchase enforcement are not included. Tournament Lite is not included.
